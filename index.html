Featured case study

mk19 robotic hand: mechanism, controls, and validation in one system.

My flagship project is a linkage-driven compliant hand that uses a buckling drive joint to create contact-triggered distal motion. The case study shows mechanism reasoning, Simulink/MuJoCo control workflow, Python servo tooling, early hardware validation, and a clear path toward co-optimization with reinforcement learning and variable-stiffness integration.

3 motorsCompliant mechanics create useful contact behavior with modest actuation
MuJoCoHand behavior and object contacts approximated with MuJoCo simulation
FDMAll actuation paths and compliant components can be FDM printed as a monolithic piece.
TCP bridgeSimulink commands Python/MuJoCo plant server through a reusable boundary
  • Mechanism: sliding drive joint, buckling driving joint, distal wrap after proximal blockage, and a reserved stiffness channel for later VSJ work.
  • Controls: current-limited PID tuning separates free-space bending from contact/grasp authority.
  • Verification: plots and media document bend target, torque/current sweep, free-space response, and proximal-blocked compliant motion.
